# Vila do Sol: Corre das Lajes

Versão web/PWA exportada com Godot 4.7.2.

Jogar: https://joaovitorsw.github.io/vila-do-sol-corre-das-lajes-web/

No celular, use a tela na horizontal. Android/Chrome: Instalar app ou Adicionar à tela inicial. iPhone/Safari: Compartilhar → Adicionar à Tela de Início.

Aguarde o carregamento completo e recarregue uma vez online antes de testar offline. Saves ficam no navegador/dispositivo, sem sincronização com Windows.

Este repositório contém a distribuição web exportada. Licença do engine: GODOT-LICENSE.txt.
